n8n 3.0 Compose verification

The default stack starts SearXNG and configures n8n Assistant to use managed Daytona sandboxes. A PostgreSQL-backed workflow survived the upgrade from 2.39.8 to 3.0.1.

Deployment setup

  • n8n and the distroless Code node runners share the 3.0.1 pin. This is an early-access release for a controlled demo. Use a maintained version containing n8n’s 3.2.2 security fixes for public deployments. 3.0.1 release · Security advisories
  • Daytona provisions Assistant sandboxes remotely and handles the workflow data Assistant passes to them. The local Compose stack uses zero privileged containers. A Daytona API key and a model provider key activate Assistant. n8n Assistant setup guide
  • SearXNG has a private network shared with n8n, an HTTP health check, resource limits, log rotation, and a named cache volume. It runs as a non-root user with a read-only root filesystem and no Linux capabilities.

Review fixes

Claude Opus 5.5 and an independent Codex reviewer reviewed PR #4.

  • The quick start now keeps the 3.0.1 demo local while the owner account is created. The public ingress instructions require a patched version.
  • Compose leaves the model name to n8n unless the operator sets it explicitly. This preserves the upstream default and editor model selection.
  • The upgrade instructions explain that an existing environment file needs a new SEARXNG_SECRET before using the new Compose file.

Observed results

  • Compose resolved five default services. SearXNG had zero published ports and joined only the search network. n8n joined both the default and search networks.
  • In an isolated ARM64 Docker project, PostgreSQL and n8n passed their health checks, and the sandbox configuration reported enabled=true provider=daytona.
  • A published webhook ran through the external JavaScript Code runner before and after the version upgrade. It also ran with SearXNG stopped.
  • On a fresh 3.0.1 install, the authenticated Assistant settings API accepted a model and test credential. Its search verification returned a result through SearXNG from a local fixture engine. The default upstream search engines timed out.
  • A temporary ngrok HTTPS endpoint with a test Traffic Policy reached the fixture webhook and blocked editor and unauthenticated requests. The test used the local ngrok agent. The exact Compose ngrok service, live Daytona provisioning, and model-backed chat remain unverified.

Reproduce startup

Fill in the values from .env.example, including a unique SEARXNG_SECRET. For an existing instance, review the Migration Report and back up PostgreSQL, the n8n data volume, and the encryption key before upgrading. 3.0 migration guidance

docker compose config --quiet
docker compose up -d --wait n8n task-runners searxng
docker compose ps
